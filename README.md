# 🎨 Diseño de Interfaces Web (DIW) — 2º DAW

Repositorio oficial para las prácticas, ejercicios y proyectos de la asignatura **Diseño de Interfaces Web (2º DAW)**.

---

## 🌿 Flujo de Trabajo (Git Workflow)

Este repositorio utiliza una estrategia de ramificación estructurada para el desarrollo:

* **`rama específica` (feature branches):** Cada práctica o batería de ejercicios se desarrolla de forma independiente en su propia rama. Cada una cuenta con su propio `README.md` detallado.
* **`develop`:** Rama de integración donde se fusionan las prácticas y ejercicios antes de pasar a producción.
* **`main`:** Rama principal y estable que contiene la versión final del código listo para entregar.
